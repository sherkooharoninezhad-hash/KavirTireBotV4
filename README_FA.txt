# ربات پایش موجودی کویر تایر

## محتویات
- `kavir_tire_bot.py` : برنامه ویندوزی با رابط گرافیکی
- `build_exe_windows.bat` : ساخت فایل EXE روی ویندوز

## نکته مهم درباره فایل EXE
محیط فعلی ساخت، ویندوز نیست؛ بنابراین فایل اجرایی Windows را نمی‌توانم اینجا کامپایل و تست کنم.
برای ساخت EXE روی یک سیستم Windows:
1. Python 3.11 یا 3.12 را نصب کنید و هنگام نصب گزینه Add Python to PATH را فعال کنید.
2. مطمئن شوید Google Chrome نصب است.
3. همه فایل‌های این پوشه را استخراج کنید.
4. روی `build_exe_windows.bat` دوبار کلیک کنید.
5. پس از پایان، فایل `dist/KavirTireBot.exe` ساخته می‌شود.

پس از ساخت، اجرای EXE به نصب جداگانه کتابخانه‌های پایتون نیاز ندارد؛ فقط Google Chrome باید روی ویندوز موجود باشد.

## روش استفاده
1. برنامه را اجرا کنید.
2. «باز کردن مرورگر و ورود» را بزنید.
3. برای دریافت لیست، «دریافت / نوسازی فهرست محصولات سایت» را بزنید.
4. محصول، سایز، مدل و تعداد حلقه (۱ تا ۴) را انتخاب کنید.
5. «رفتن به صفحه فروش» را بزنید و شخصاً وارد حساب شوید.
6. پس از رسیدن به صفحه فهرست موجودی فروش، «شروع پایش» را بزنید.
7. برنامه هر ۴ ثانیه دکمه بروزرسانی موجودی را می‌زند و فقط در صورت یافتن دکمه دارای متن صریح افزودن/سبد خرید آن را کلیک می‌کند.
8. پس از انتقال به مرحله بعد، تعداد و جزئیات را کنترل کرده و پرداخت را شخصاً انجام دهید.

## محدودیت فعلی
- سایت ممکن است ساختار دکمه‌ها یا مسیرهای خود را تغییر دهد. در این صورت انتخابگرهای پایش باید با صفحه زنده تطبیق داده شوند.
- تشخیص رنگ به‌تنهایی برای کلیک استفاده نمی‌شود تا از خرید اشتباه جلوگیری شود.
- ورود، کپچا، انتخاب درگاه و پرداخت به‌صورت دستی باقی می‌ماند.
- این نسخه به‌صورت کد اولیه قابل ساخت ارائه شده و لازم است روی حساب و صفحه واقعی کاربر آزمایش شود.
